## 1. 产品背景

- 腾讯混元 **2026-08-04** 发布新一代语音识别模型 **Hy ASR 3.0 preview**，已上线腾讯云官网提供 PaaS API。
- 依托 **Hy3 基座大模型**（混合专家架构），打通「声学识别 + 深度语义理解」双链路，把 ASR 从「听清」带向「听懂」。
- 腾讯元宝 App 已首发接入（面向用户免费）。
- 引擎参数名：**`Hy-ASR-3.0-preview`**。

## 2. 能力

### 2.1 核心能力
- **中英 + 20 种方言**混合引擎：普通话、英语，以及粤语、东北话、河南话、陕西话、成都话、重庆话、武汉话、贵阳话、青岛话、济南话、长沙话、合肥话、河北话、昆明话、兰州话、银川话、南昌话、北京话、四川话、天津话等。
- **上下文感知**：基于 Hy3 语义理解，识别时结合上下文修正，更接近说话人意图。
- **多语种词错率（WER）稳定约 3%**，中文识别准确率领先。
- **产品定位**：PaaS 级实时语音识别，适用于 IM 语音转写、实时字幕、智能助手语音指令实时解析等低延迟场景。

### 2.2 当前限制（内测版）
依官方文档，内测阶段部分功能暂不支持：
- **仅支持 1 分钟以内的语音**。
- **仅支持 16k 单声道 PCM** 音频输入。
- **不支持**话者分离、VAD、词汇替换、噪音参数阈值。
- **上下文传入与热词功能即将开放**（当前不可用）。

> 对 VoiceX 影响：VoiceX 的免提/长按听写通常为短句，1 分钟限制可满足大多数场景；但「录后批量精修」等长录音路径不适用。

## 3. 接入方式

### 3.1 总览
- 走 **腾讯云实时语音识别（WebSocket）** 接口：`wss://asr.cloud.tencent.com/asr/v2/<appid>?{请求参数}`。
- 仅需在请求参数 `engine_model_type` 传 **`Hy-ASR-3.0-preview`** 即使用混元识别。
- 鉴权：**签名鉴权机制**（腾讯云 API v3 签名），需 AppID、SecretID、SecretKey。

### 3.2 步骤
1. **开通语音识别服务**（控制台开通）。
2. **新建密钥**：控制台生成 AppID、SecretID、SecretKey，用于签名鉴权。
3. **调用**：WebSocket 实时流式识别，`engine_model_type = Hy-ASR-3.0-preview`。

### 3.3 与 VoiceX 架构的映射
- VoiceX 已有成熟的 WebSocket 流式 ASR 客户端（豆包 `bigmodel_async`、Fun-ASR、Qwen 等），**新增一个 provider 客户端即可复用现有 stream 管线**。
- 需新增：Tencent 鉴权签名（腾讯云 v3 签名）、WebSocket 协议编解码、`engine_model_type` 配置字段。
- 能力矩阵：`supports_realtime = true`，`supports_batch = false`，`supports_post_recording_batch_refine = false`（受 1 分钟限制）。

## 4. 价格

Hy-ASR-3.0-preview **按「大模型 2.0 版」计费体系**，与普通实时语音识别区分。

### 4.1 免费额度 / 并发
- **免费并发路数：20 路**。
- **大模型 2.0 版无免费调用时长**（普通版实时语音识别才有每月 5 小时免费额度）。

- 按时长计费，最低单位 1 秒；秒转小时 × 单价，四舍五入到小数点后 2 位。
- 预付费资源包有效期 1 年，超额转后付费。
- 后付费为日结；大模型 2.0 实时识别无免费额度，从第一秒起计费。

## 5. 评估与建议

### 5.1 优势
- **中文/方言识别领先**（WER ~3%），对 VoiceX 中文用户是强诉求。
- **价格极低**：按 2.0 版预付费约 **1 元/小时** 起，比豆包/阿里主流中文 ASR 具竞争力。
- 接入成本低：复用现有 WebSocket 管线，仅新增鉴权 + 协议。

### 5.2 风险 / 限制
- **内测版**：功能受限（1 分钟、16k PCM、无热词/上下文/话者分离），正式版未知。
- **无免费时长**：需付费，且无批量路径。
- 方言范围偏「国内口音」，与豆包/阿里覆盖重叠，需实测对比。

### 5.3 结论
**暂不接入，密切关注。** 理由：
- 收费可接受（约 1 元/小时），但**内测版仅支持最长 1 分钟音频**，无法覆盖 VoiceX 的免提听写/长按键说话/录音回放等核心场景，基本没有使用价值。
- 无批量路径、无热词/上下文，进一步限制适用性。
- 建议：**作为技术候选登记，持续跟踪正式版**。一旦放开时长限制（或提供批量文件识别），再做同音频实测对比后评估接入。
